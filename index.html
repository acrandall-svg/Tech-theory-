🧠 Day 3: Problem-Solving Mindset

💡 Mindset Comparison: Two Approaches to the Same Problem
Scenario: A student approaches you: "This computer is broken. It won't let me save my document."
❌ Problem-Fixing Approach
  • Quickly tries different save options
  • Restarts the application
  • Says "Try again now"
  • Moves on to help next person
Click to see what's wrong with this approach
✅ Problem-Solving Approach
  • Asks when the problem started
  • Has student show exactly what happens
  • Explains what each solution attempts to fix
  • Teaches student to recognize and prevent the issue
Click to see why this approach is better

Problems with the Problem-Fixing Approach:

  • No root cause identification - Problem may recur
  • Student learns nothing - No prevention knowledge gained
  • No documentation - Pattern can't be tracked
  • Creates dependency - Student will return with same issue

Result: You'll likely see this student again with the same problem because they don't understand what caused it.

Benefits of the Problem-Solving Approach:

  • Identifies root cause - Prevents recurrence
  • Builds user confidence - Student gains understanding
  • Creates learning opportunity - Knowledge transfers to other situations
  • Reduces future tickets - Student becomes more self-sufficient

Result: Student becomes more independent and confident with technology, reducing repeat problems.
